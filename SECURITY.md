# Security Policy

## Reporting a vulnerability

Report security or privacy vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/starvingarc/BRIDGE/security/advisories/new).
Do not include credentials, private data, internal sample identifiers or server
paths in a public Issue or Pull Request.

Include the affected BRIDGE commit or Tool Package version, the smallest safe
reproduction, expected impact and whether any sensitive data may have been
exposed. If a safe reproduction cannot be shared, describe the boundary without
copying the protected content.

## Supported version

BRIDGE is currently a research-use candidate without a tagged stable release.
Security fixes target the current protected `main` branch. Engineering support
does not imply scientific, clinical, safety, potency or GMP validation.
