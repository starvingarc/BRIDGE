# Security Policy

## Reporting a vulnerability

Report security or privacy vulnerabilities through GitHub's
[private vulnerability reporting](https://github.com/starvingarc/BRIDGE/security/advisories/new).

Reports identify the affected BRIDGE commit or Tool Package version, the
smallest safe reproduction, expected impact and whether sensitive material may
have been exposed. Additional protected evidence is handled through the private
reporting channel.

## Supported version

BRIDGE is currently a research-use candidate without a tagged stable release.
Security fixes target the current protected `main` branch. Engineering support
does not imply scientific, clinical, safety, potency or GMP validation.
