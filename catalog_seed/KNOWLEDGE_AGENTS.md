# Knowledge Catalog Rules

Method Cards, Source Cards, bindings, aliases and retrieval chunks in this directory are generated facts.

- Do not hand-edit generated Method or Source Cards. Change `catalog_seed/`, the source-verification record or `tools/build_knowledge_catalog.py`, then regenerate.
- Preserve all original capability bindings and explicit alias ambiguity; never merge methods from names alone.
- A reachable URL proves provenance access only. It does not promote scientific status, evidence tier or formal eligibility.
- `competitor_isolated` material cannot enter the retrieval projection used for BRIDGE planning, priors, calibration or formal evidence.
- Restricted full text is not stored here. Record only Source ID, metadata and access policy.
- Regeneration must be deterministic and pass catalog, privacy and dangling-reference checks.
