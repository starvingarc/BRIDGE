# Legacy BRIDGE

`legacy/v1/` contains the historical Step1-Step3 implementation, documentation, tests and configuration.

It is preserved for provenance only. It is excluded from package discovery, active tests, public APIs and Agent tool registration. No result produced by this code is automatically valid under BRIDGE v2 contracts.

The archived `bridge_v2_runtime_audit_20260803` records machine-specific environment observations from an earlier documentation pass. It is superseded by the generic Conda contracts under `environments/` and must not be used as an installation specification.
