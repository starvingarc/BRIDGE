# Workbench screenshots — 2026-10-15

Three browser screenshots document the development preview in the
[root README](../../../README.md). All use the light theme and a dedicated demo
account. They are captures of the running application, not design mockups.

- **Protocol editor:** an illustrative protocol created for the demonstration.
  The reagent schedules and doses are not laboratory records or recommendations.
- **Reference mapping:** the configured developmental-reference visualization
  with a projection of public sample
  [GSM6194010, stage III / day 21](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSM6194010),
  from [GSE204796](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE204796).
  Underlying reference matrices and reference assets are not distributed here.
- **QC:** results computed by the application from the same public sample.
  Missing capture declarations remain unassessed rather than being invented.
  Sample projection, QC and cell-cycle outputs are descriptive research evidence,
  not independent biological validation or a product-quality judgment.

The public sample was loaded into a separate demonstration research space.
Calendar dates and research containers are presentation scaffolding, not original
laboratory records. The protocol editor example is separate from this sample.
No private samples, personal account details, credentials, deployment addresses
or local filesystem paths are included. The JPEG files contain no EXIF metadata.

These screenshots illustrate a development build ahead of the public source
snapshot; installing the public snapshot does not reproduce these views yet.
