# Protocol 流程可视化与信息查阅

## 用途与当前交付

当研究者上传自己的分化 protocol 后，模型阅读已有的受控提取内容，整理有来源的阶段、时间、操作、试剂与培养条件。用户核对这些信息后，以可交互流程图呈现；点击阶段、试剂或添加窗口，可查阅原文依据、小分子结构、作用信息和参考分化流程。

本目录交付这条用户路径的设计资产与可运行参考示例，服务于 PRD 的 [Materials / 来源事实确认](BRIDGE_PRD.md#61-agent-总体工作流) 及 [可视化交互](BRIDGE_PRD.md#66-visualization-composer-与-web-交互)。现有 protocol 读取、来源核对和 BPL 表示仍由 [Protocol formalization](protocol-formalization.md) 维护。本次没有接入上传接口或模型，没有实现从任意 protocol 自动生成流程图，也没有修改科学测量、报告资格或正式知识快照。

参考包见 [examples/protocol-visualization](../examples/protocol-visualization/README.md)。它包括：

- 最终灰线白底的脑类器官流程示例、阶段形态示意和试剂类别图标。
- 人 iPSC/hESC 二维及三维中脑 DA 小分子图鉴：32 个条目、72 条方法记录、可下载的结构图。
- 搜索、模型/用途筛选、阶段与试剂展开、来源跳转、结构图下载的交互参考。

## 目标用户路径

1. **上传自己的 protocol。**沿用已有附件和受控读取流程；不将原始私人文件发布到本参考包。
2. **模型提取并整理。**每个阶段、日期、剂量、条件和试剂关联原文定位。只依据当前上传版本；未报告和有歧义的字段保留未知，必要时追问。
3. **用户核对。**展示可读摘要、原文引用与待确认项，用户可以逐项修订、补充或明确“不确定”。修订形成新版本，不覆盖原始材料。
4. **显示可交互流程图。**按已确认的时间与阶段排列；显式标记估计、条件性端点和未知时长。若没有可靠日期，用顺序图，不伪造按比例时间轴。
5. **按需查阅。**点击阶段显示操作、培养条件、预期形态与来源；点击试剂显示身份、结构、该 protocol 的添加窗口及用途；另行查看文献中的参考路线和使用记录。

## 交互语义

| 交互对象 | 展示内容 | 边界 |
|---|---|---|
| 阶段图像或名称 | 阶段条件、原文定位、所用培养基 | 插图是示意，不是用户实验照片或已观察到的结果 |
| 时间区间 | 开始/停止规则、原文时间、浓度 | 条件性停止不改为固定停止日；半量换液不意味着残留立即归零 |
| 试剂类别图标 | 分子/蛋白/多糖/复合补充剂 | 简化类别符号不冒充该物质的化学结构 |
| 小分子详情 | 名称、别名、结构来源、对应方法记录 | 盐型、异构体、未确认身份不得因名称相似自动合并 |
| 参考分化流程 | 独立文献的路线及适用细胞类型 | 不自动补入用户 protocol，不拼接不同论文成为新配方 |
| 搜索/筛选 | 名称、别名、用途、2D/3D、路线 | 未匹配显示缺失；条目数量或出现频次不是证据强度 |
| 下载 | 当前选定结构素材或版本化展示结果 | 原型结构导出不代表正式报告或公开导出授权 |

关键信息不能仅靠 hover、颜色或图标表达。按钮支持键盘和触控；详情保留文字、来源与缺失状态。复杂小分子保留完整骨架，默认紧凑显示，点击后展开完整结构；蛋白和混合物用类别插图并明确标注。

## 后续产品接线原则

复用已有 protocol 表示、HumanStep、源定位及审阅版本。为展示增加窄的只读投影；模型不直接生成任意可执行 HTML/JavaScript，前端不接收另一模块的内部状态。图中的节点和引用必须绑定同一附件与确认版本；用户改动时间或条件后，旧图标为历史状态，重新核对后才生成新图。

建议的展示信息包括阶段标签/顺序、原文时间和归一化时间（可为空）、日期锚点、试剂原文/身份状态、剂量原文/单位、操作与结束条件、来源定位及用户确认状态。这是实现方向，不是本 PR 新增的公开 Schema。BPL 编译通过也不证明每个条件都已理解或实验已经执行。

参考小分子查阅与用户实际方案分区显示。明确标为“参考文献”与“用户 protocol”；同一条目可用于查阅，不能因此取得修改科学 reference、prior、阈值、正式知识或报告资格的权限。以后若向模型发送新范围的 protocol 或联网检索内容，仍按已有隐私与授权合同处理。

## 来源与科学限制

脑类器官示例来自 Lancaster–Knoblich 2014，**不是中脑 DA 定向分化流程**。形态参考其图 2/3 经 AI 辅助重绘；并非显微照片、比例尺或唯一正确形态。图 2a 为 hESC，起始图只借用通用多能细胞集落形态。详情见素材来源说明。

小分子库是候选参考资料：PubMed 宽检索返回 596 条，未逐篇完成全文筛选，不能宣称穷尽所有相关文献。历史/混合中脑神经元/转录因子辅助路线有独立标识；SAG21k 的人源中脑培养使用已定位，但高纯 mDA 终点和具体剂量仍待核实。cAMP 产品身份、guggulsterone E/Z、部分 AA 单位和 Ara-C 日期剂量冲突保留未决。

不收录论文全文、原始显微图、用户附件、部署配置、模型响应或私有运行记录。基础培养基的所有营养组分未全量展开；SHH、FGF8、BDNF 等蛋白以及 N2/B27/CEPT 等混合物不假造单一小分子结构。

## 后续接入的验收条件

- 对一个授权、非敏感 protocol，从上传、提取、用户核对到交互图走通；图中每项可回到同一版本原文。
- 覆盖未知日期、条件结束、原文冲突、歧义试剂、单位转换未经确认、多方案文件及用户更正；不得静默补齐。
- 验证阶段、添加窗口、详情文字、静态导出与机器可读记录一致；桌面/窄屏及键盘路径可使用。
- 原型检查只证明素材及交互可用；真实模型提取准确性、研究者接受度与科学资格分别验证。
