# 产品 UMAP 与空间参考联动

状态：工程实现、内部真实样本的探索性联动及浏览器检查已完成；人工生物学审阅与科学资格尚未确立。此设计扩展现有结果展示，保留既有上传、背景确认、分析授权及 QC 流程。

## 目标与页面

研究者输入一个细胞产品批次的数据，经既有 Agent 和注册工具处理后，在结果页同时查看产品细胞群和对应参考类型的组织分布。

- 左侧约 45%：产品 UMAP；默认按候选细胞类型着色，可切换原始聚类。显示批次、分析版本、选中群的细胞数和产品内比例。
- 右侧约 55%：真实空间坐标图为主。保留完整组织轮廓，匹配类型高亮，其余细胞淡灰。切片选择器区分捕获样本及可确定的单张组织切片。
- 右上角约 180–220 像素：半透明三维胚胎及候选切面，仅作参考，可旋转和折叠。默认不遮盖空间点图。小屏改为上下排列。
- 下方简短信息区：对应类型、对应依据、候选/未知状态及数据来源。方法细节折叠，Agent 对结果的解释不占据主画布。

未锁定时，悬停群或图例临时高亮；图中候选类型稳定停留 120 ms 后更新，避免交界处抖动，离开恢复全图。点击群锁定后，悬停或键盘焦点不覆盖锁定项；再次点击明确切换或取消，点击清空按钮或按 Esc 解除并取消待处理预览。键盘可聚焦类型列表，用 Enter 完成选择。左右相同类型使用相同颜色，各自图例放在图侧，窄卡片保留可读的下方布局。

## 联动含义

右侧表示“产品中该群对应的参考细胞类型，在参考胚胎切片中的观测分布”。它不表示产品细胞的物理位置，不是移植归巢预测，也不需要先完成三维配准。

第一版采用版本化的标签对应表。每条对应含产品状态 ID、空间类型 ID、关系（同类型或较宽类型）、依据、审阅状态和资源版本。标签字符串相似、UMAP 上靠近、颜色相同都不能自动建立对应。只有明确且已审阅的对应可触发高亮；候选注释自身的科学状态保持候选。

默认按细胞类型联动。聚类模式下，一个群混有多种类型时，显示其实际组成，并高亮其中已有对应的类型集合；不能将整个群强制命名为占比最大的类型。展示各类型的对应关系和未匹配部分。第一版不引入表达相似度空间投射或加权位置预测。

- 没有对应关系：显示“暂无空间对应”，保留灰色参考底图。
- 对应类型在所选切片中没有观测细胞：显示“此切片未观察到该参考类型”，不解释为普遍不存在。
- 产品注释拒绝或未知：保留原状态，不自动分配位置。
- 空间来源、图像或注释不可用：保留产品 UMAP，说明缺少哪一项。

## 数据与责任边界

### 既有能力

现有 P0-02 表达探索可输出绑定输入版本的 UMAP 和逐观测表；候选注释路径可输出逐细胞 assignments。`ExpressionUMAP` 保留独立 Canvas 展示、着色与过滤，联动容器通过可控 `ProductScatter` 共享预览及锁定状态。三维模型同时具有独立预览与结果页参照入口。

### 新增展示数据

产品视图由同一 QC-selected DataView 的 embedding、注释及聚类组成。连接前必须核对输入 hash、DataView 引用、观测标识与顺序校验。当前图 JSON 的 record_id 可以是观测索引，不能把它直接当成细胞条码；应通过完整逐观测表和有校验的顺序显式解析。拒绝跨批次、跨筛选版本或错序的拼接。

空间参考包含：资源及注释版本、capture/section 标识、逐观测二维坐标、类型 ID、完整计数，以及可选的组织图像和已验证的像素变换。对应表绑定产品词表与空间词表两侧的精确版本。

生成一个来源绑定的联动视图清单，引用上述产物及其 hash，记录对应状态和缺失原因。它是既有结果的确定性展示衔接，不生成新的生物学 MeasurementResult。复用现有 artifact 权限与读取路径；不得把私有数据放入前端静态包或新增未鉴权文件接口。

职责分别为：

1. Agent 复用已有流程，在已授权范围内安排 QC、表达探索和候选注释，记录真实工具执行状态。结果未完成时不展示伪造的 UMAP。
2. 工具/结果适配层负责产生并验证逐观测连接与视图清单，不用 LLM 文本连接细胞。
3. 空间参考适配层只读取已登记资产和既有坐标/标签；本功能不重新聚类、注释或配准参考数据。
4. React 联动容器持有 hover/pinned 类型集合；产品图、空间图和小型三维模型各自接收窄输入，不读取对方内部状态。

## 原始材料与显示限制

当前受控空间对象含已有 UMAP、二维空间坐标与细胞类型，可以验证真实空间点图交互。捕获图上下摆放的组织切片分别存在，不把上下间距解释为胚胎内深度。无法确认独立切片身份时按捕获样本显示，并明确其内含多张组织切片；不按简单 y 阈值自动认定层序。

原始全分辨率 H&E 及其来源变换尚不齐备。第一版以真实坐标形成的细胞类型图为主，不把带坐标轴、红点和边框的历史叠加 PNG 当作纯 H&E 底图。补齐可验证像素变换后，可开启背景开关及透明度控制。历史图像可在来源详情中单独查看。

三维模型及蓝色切面始终标记“解剖参照 / 候选切面，未配准”。悬停群不改变切面位置，也不在模型内生成假定的细胞云。三维资源沿用已有 HDBR 来源和许可说明。

当前注释方法的适用性和 OOD 限制继续显示；联动成功不提升标签资格，也不把产品与空间参考的不同发育阶段解释为等价。

## 渲染与计数

空间数据量较大，使用 Canvas 与预建的类型索引，先绘制灰色背景，选择变化只更新高亮层。高亮以真实坐标为准，位置不加抖动、不随机生成。若性能要求确定性抽样，必须按类型保留稀有群并显示绘制点数、完整计数与规则；所有产品比例、空间计数使用完整数据，产品与空间的分母分别标明。

空状态、加载、分析失败、注释不可用、参考缺失、对应缺失分别表达，不能统一为“0 个细胞”。

## 第一版验收

- 同一产品数据从既有输入/Agent 流程到真实 UMAP 与注释产物，再到联动结果页；记录输入、运行和产物版本。
- 至少一个明确对应类型：鼠标悬停后空间图只高亮预期类型的真实坐标；完整计数与输入表一致。
- 混合群、未知群、无对应和所选切片零观测均有可核对行为。
- 点击锁定、悬停不覆盖、Esc 清空、切换切片、键盘列表操作一致；更换批次或版本清空旧选择。
- 错序观测、不同 DataView、陈旧对应表和无权访问的空间资产被拒绝，不静默拼接。
- 三维模型保持小型参考，隐藏/失败不会阻止 UMAP 和空间视图使用。
- 当前桌面窗口和窄屏检查可读性、交互及加载/失败状态；大数据交互做实际性能观察，不以静态截图代替。
- 工程验证、真实数据联动验收与科学资格分别报告。若产品分析结果或审阅对应表尚缺，仅能报告参考侧/工程验收完成。

## 非目标

本次不新增产品/项目管理体系，不重做已存在的上传与 QC，不训练新的空间投射模型，不推断完整胚胎三维细胞分布，不改变评分或科学冻结合同，不自动发布数据、合并或部署。
