# P0-05 Off-target Control

Declared-denominator composition and off-target evidence accounting. Product-bound
modes apply externally reviewed role mappings; saved-context mode reuses checked
candidate observations without rerunning a matrix. Candidate labels do not
establish product roles, purity, safety or a domain score.

The [Tool Card](../cards/P0-05.md) owns the current versions, four input modes,
outputs, invocation and rejection behavior. Use `bridge-tool describe P0-05` and
`bridge-tool input-contract P0-05` to inspect the installed interface.
