# P0-01 Input Audit & QC

## Purpose

Validate expression inputs and emit a QC readiness profile.

## Contract

| Field | Value |
|---|---|
| Package version | `0.1.0` |
| Runtime state | `implemented` |
| Scientific state | `candidate` |
| Optional | `no` |
| EnvironmentSpec | `ENV-P0-CORE-v0.1` |
| Input schema | `bridge://schemas/tool-request/v0.1` |
| Output schema | `bridge://schemas/tool-run/v0.1` |

**Input:** A declared h5ad, 10x H5, or 10x MTX asset; input level, assay, matrix semantics, sample/capture metadata, gene-identifier source, and output location.

**Output:** Raw structural and QC metrics, the backward-compatible `QCReadinessProfile`, additive `qc_readiness_profile_v2.json`, candidate data views when a candidate MeasurementSpec is selected, visualizations, and a checksummed artifact manifest. When explicit versioned biological-unit metadata is complete, P0-01 also writes `biological_unit_assignment.json` and `biological_unit_manifest.json`; all three additive JSON artifacts are checksummed and listed in the run artifact manifest.

**Runtime behavior:** Executable candidate; it emits raw measurements and never emits a domain score.

The v2 profile binds the exact immutable input asset, matrix location, matrix semantics and observation-ID digest. Its lineage is caller-declared only. P0-01 does not infer preparation, sample, donor, animal or independence from filenames, directories, `sample_id`, `capture_id`, cell counts or capture structure. Missing or invalid lineage metadata returns an explicit v2 `unavailable` state without invalidating an otherwise legal v0.1 run.

`asset.metadata.biological_unit_lineage` may declare versioned unit references through `observation_ref_columns` and/or `constant_unit_refs`. It must explicitly provide `source_unit_kind`, `source_unit_ref`, `unit_identity_namespace_ref`, `analysis_unit_kind`, `independence_group_kind` and `independence_scope_ref`. Technical captures and graft units cannot be independence groups. Constant references are declarations applied to every observation, not evidence that the declaration is biologically correct.

## Refusal Conditions

Unreadable or ambiguous matrix, duplicate identifiers, invalid count semantics, missing assay, missing required sample/capture information, unsupported MeasurementSpec/input-level pairing, an incomplete declared gene-symbol column, or an output directory nested inside a directory input.

Missing, unknown, unavailable, negative, and alert states remain distinct. `declared` does not mean `reviewed`, `frozen`, statistically independent or biologically validated. No package may infer a clinical, safety, potency, GMP-release, or absolute product-ranking claim.

## Visualization Contract

Per-sample QC distributions and counts-versus-detected-genes diagnostics with explicit denominators.

Every formal chart must retain its data version, denominator, units, evidence references, and missing-state semantics.

## Validation Before Freeze

Format fixtures, scRNA/snRNA contracts, matrix-semantic failures, deterministic reruns, input immutability, and optional Scrublet eligibility.

Method documentation and accessible sources do not constitute benchmark completion. The registered method IDs are returned by `bridge-tool describe P0-01`.
