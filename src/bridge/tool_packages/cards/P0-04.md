# P0-04 Developmental Compatibility

## Purpose

Aggregate an upstream P0-02 composition channel into externally reviewed
`earlier`, `within_window`, `later`, `branch_shift`, and `unresolved` roles. The
package reports whole-product and target-related denominators. It does not encode
state identities, markers, fetal-age conversions, thresholds, or a score.

## Contract

| Field | Value |
|---|---|
| Package version | `0.2.0` |
| Runtime state | `implemented` |
| Scientific state | `candidate` |
| Optional | `no` |
| EnvironmentSpec | `ENV-P0-CORE-v0.1` (`health_check_passed`) |
| Input envelope | `bridge://schemas/tool-request/v0.2` |
| Output envelope | `bridge://schemas/tool-run/v0.2` |
| Result schema | `bridge://schemas/developmental-compatibility-result/v0.1` |
| Adapter | `bridge.tool_packages.p0_04_developmental_compatibility.adapter:adapter` |

## Interface

P0-04 accepts `ToolRequestV2` with six required, versioned, local JSON objects.
Each `StructuredInputRef` supplies an absolute path, exact SHA-256 checksum,
schema reference, object version, role, and `application/json` media type.

| Role | Required | Schema | Meaning |
|---|---:|---|---|
| `product_case` | yes | `bridge://schemas/product-case/v0.1` | Case, assay, product and measurement binding |
| `product_definition_card` | yes | `bridge://schemas/product-definition-card/v0.1` | Product scope; remains a draft scientific input |
| `development_window_spec` | yes | `bridge://schemas/development-window-spec/v0.1` | External window review and composition channel |
| `development_state_map` | yes | `bridge://schemas/development-state-map/v0.1` | External stage-role and target-related mapping |
| `measurement_spec` | yes | `bridge://schemas/measurement-spec/v0.2` | Measurement and biological-unit contract |
| `cell_state_evidence_profile` | yes | `bridge://schemas/cell-state-evidence-profile/v0.2` | P0-02 composition, provenance and state |
| `development_timepoint_series` | no | `bridge://schemas/development-timepoint-series/v0.1` | Declared real timepoints; no fetal-age conversion |

Expression assets, top-level measurement parameters, arbitrary parameters and a
non-zero random seed are refused. P0-04 does not rerun single-cell analysis.

The output is one checksummed `developmental_compatibility_result.json`. It binds
all inputs and checksums, reports the upstream state, two denominator profiles,
optional descriptive timepoints, evidence references and reason codes. Every run
retains `domain_score=null` and `score_state=unavailable`.

## Calls and example

```bash
bridge-tool describe P0-04
bridge-tool validate --request examples/requests/p0_04_developmental_compatibility.json
bridge-tool run --request examples/requests/p0_04_developmental_compatibility.json
```

Python uses `ToolRegistry.load_default()`, `parse_request(payload)`,
`check_eligibility(request)`, and `run(request)`. The documentation example uses
placeholder absolute paths and checksums; replace them with real local objects.

## Missing, unavailable and refusal behavior

- `missing`, `unknown`, `unavailable`, or `not_assessed` upstream composition is
  an eligible `not_assessed` run and is never converted to zero.
- An unconfirmed window returns a profile but no compatibility conclusion.
- Unmapped/residual counts become `unresolved`; a zero target denominator has
  null fractions.
- Zero or one timepoint is static; two or more are descriptive. Inferential
  time-course and in-vitro-day/fetal-stage conversion are unavailable.
- Schema, checksum, version, cardinality, assay or object-binding mismatch returns
  a typed failed run with stable reason codes and no artifact.
- Reference-stage support is explicitly unavailable in this first version.

## Scientific boundary

Methods are registered but not formally eligible. Candidate/shadow output is
engineering evidence only, not biological truth, clinical or safety evidence,
release permission, efficacy, or an absolute product ranking.

## Validation

Focused tests cover valid execution, deterministic reuse, checksum/schema
failures, object bindings, unconfirmed windows, unavailable evidence, unresolved
counts, zero target denominator and descriptive timepoints. Record:
`docs/validation/p0_04_developmental_compatibility_v0.2.md`.
