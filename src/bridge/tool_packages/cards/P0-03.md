# P0-03 Target Identity & Regional Fidelity

## Purpose

Bind a P0-02 V3 composition to one ProductCase and external role definitions.
The default mode publishes three denominator-explicit ratios from precomputed
composition. An optional expression mode also executes configured target and
regional evidence methods on the exact QC-selected H5AD view.

## Saved similarity projection

`saved_reference_similarity_projection` accepts one `saved_reference_similarity_run`
(`tool-run/v0.2`, object version `0.2.0`), no assets, parameters or measurement-spec
override, and seed zero. The original successful/partial native P0-03 receipt,
result artifact, exploratory input and reference manifest must retain matching
checksums. Producer, view, assay, source/profile/label and finite coefficient
bindings are checked without opening expression or reference matrices.

Raw exploratory execution and saved projection publish `native_measurement_spec`
(`measurement-spec/v0.3`) and `native_measurement_N` (`measurement-result/v0.2`)
artifacts. Read these full checksummed artifacts: ToolRunV2 retains only legacy
measurement summary fields when serialized. Join `metric_name` to
`raw_metric_definition[metric_name]` for original label, level, profile, source,
coverage and reference hashes. `input_contract` binds input, original producer
and reference manifest; projections add the original receipt/result hashes and
an explicit no-matrix-execution derivation. The new measurement producer is the
projection run; the native result retains its original producer. A projection
cannot be reprojected.
The projected run retains the source observation timestamp; its explicit mode
and producer distinguish derivation from a new matrix execution. Identical
requests retain identical outputs and receipt content.

Each label yields separate Spearman and cosine coefficients, not purity, cell
fractions, validated regional identity or potency. The unit is a technical view,
biological independence is unknown, independent replicate count is null, and
missing coefficients stay null. Observation kind is cell for scRNA-seq and
nucleus for snRNA-seq. Graph admission does not confer formal evidence status.

## Inputs

### Saved whole-product roles

The `saved_cell_state_context` mode consumes one checksummed saved P0-02
candidate receipt, reusing its verified non-overlapping hierarchy and selected
DataView without matrix execution. It optionally accepts a
`state_role_map` and `product_definition_card` together, with exact mutual
version references and matching assay. Both use their existing v0.1 schemas.

Each row retains its original count and whole-view denominator. Only an explicit
state assignment from a reviewed/frozen map, a source definition permitting
`evaluate`, and non-empty role source references can resolve that row's role.
Parent roles never fill absent child assignments. Parent-only, unavailable,
unmapped and unresolved rows remain in `role_unresolved`, with a reason per row.
Draft maps provide provenance but cannot resolve roles.

The `SavedTargetRoleProfile` records role counts and mapping hashes. A target
fraction is published only when the entire positive-count partition is resolved;
otherwise the target measurement is null, including its numerator/denominator.
This is accounting under the supplied map, not validated target identity.
Regional fidelity and domain scores remain null. No regional or developmental
assignment is inferred from product roles. Historical results retain their
original result schema; the new v0.2 union adds this mode.


### Exploratory reference similarity

This independent descriptive mode accepts exactly one checksummed `count_ready`
raw-count H5AD, one `reference_similarity_input` (Schema
`bridge://schemas/reference-similarity-exploratory-input/v0.1`, version `0.1.0`),
and one checked `reference_manifest` (Schema `bridge://schemas/reference-manifest/v0.1`).
The input binds the exact P0-01 `all_observations` DataView and explicitly selects
same-assay profiles with matrix and metadata. The asset ID, SHA-256, view ID and
matrix location must match the DataView. Other object roles, parameters,
top-level MeasurementSpec and nonzero random seed are rejected.

For the entire view, raw counts are summed by gene, then normalized as
`log1p(sum_counts * 10000 / total_counts)`, matching the source reference
recipe. Original labels remain separate within each source. Spearman and cosine
similarity, top/runner-up margin and shared-gene coverage are reported; low
coverage or constant vectors produce `unavailable` with null coefficients.
The analysis scope is a **technical whole-view aggregate**, not a biological
replicate. Biological independence is `unknown`, with no independent-replicate
count, interval, product role, developmental-window claim or domain score.
Output includes the unchanged typed native result and the new technical-view
spec/measurement artifacts described above. Historical 0.4.2 receipts keep their
empty measurement list; new runs expose legacy summaries plus full V2 artifacts.
New technical-view outputs can enter P008/P009 under the versioned contract
above; this does not resolve product roles or validate report conclusions.

This mode is an exploratory input to PRD Step 7-8 target/regional assessment;
it does not bypass reviewed role/window requirements or establish any of the
five-domain product assessments by itself.

Aggregation mode supplies no expression asset or method spec and requires
`random_seed=0`. Expression mode adds exactly one checksummed
`analysis_ready` scRNA/snRNA H5AD plus exactly one
`target_regional_method_spec`. The asset must identify its selected DataView
and parent asset checksum; both are matched to P0-01/P0-02 lineage. Top-level
`measurement_spec_ref` and arbitrary `parameters` are refused.

## Binding and calculation

Eligibility fails closed unless ProductCase, ProductDefinitionCard, selected
DataView, QC profile, biological-unit manifest and assignment describe the same
case and lineage. ProductCase and the P0-02 V3 profile must bind the same source
MeasurementSpec, and that source spec ID must belong to the P0-02 reference
manifest. The separate P0-03 MeasurementSpec must authorize P0-03 and match the
case assay, product applicability, analysis unit and independence group.
Vocabulary IDs/versions, reference IDs/versions and checksums, label levels,
source IDs, shared StateRoleMap ref/checksum and explicit or generic QC
eligibility must also agree.

All biological choices are external. The shared `StateRoleMap` owns product
roles. `TargetRegionalAssessmentSpec` owns requested views/sources/levels, the
product roles used for target identity and the state-ID sets used for regional
membership. Python contains no state names, genes, markers, thresholds or
product-specific target definitions.

### Expression methods

The short selectors below are aliases from the P0-03 master catalog. The package
spec registers their canonical `METHOD-*` IDs in the knowledge snapshot.

The optional mode executes only the method IDs selected in the checksummed method
spec:

The executor does not infer normalization, gene namespace, modality matching or
an acceptable NNLS residual. The method spec must bind the query and selected
references to one versioned `ExpressionSemanticsContract`. Without it, every
selected expression method is `not_assessed`. `REG-MODALITY` additionally needs
one versioned feature- and context-matched comparison group; merely observing two
different assay labels is insufficient. `TRG-NNLS` and `TRG-BOOTSTRAP` need a
versioned external maximum for the relative L2 residual. Coefficients above that
limit remain diagnostic `unknown` records and never enter bootstrap inference.

| Method ID | Runtime action | Output |
|---|---|---|
| `TRG-PBCORR` | sample-pseudobulk Spearman/cosine against target references | top label, support, runner-up margin and shared-gene count |
| `REG-PBCORR` | the same transparent calculation against a separate regional reference set | regional label support and margin |
| `TRG-NNLS` | SciPy non-negative least squares over target reference centroids, normalized to a simplex | continuous state weights, relative residual and applicability state |
| `TRG-DECOUPLER` | decoupler ULM on explicit signed target program cards | activity, p-value and observed marker coverage |
| `REG-DECOUPLER` | decoupler ULM on explicit signed regional program cards | regional program activity and coverage |
| `TRG-BOOTSTRAP` | nonparametric resampling over P0-01 independence groups | interval, or `descriptive_only` for one independent group |
| `REG-CROSSREF` | compare regional labels/support across reference profiles | agreement and support range |
| `REG-MODALITY` | compare regional evidence only inside the declared matched group | modality agreement or typed non-assessment |

Pseudobulk units and bootstrap independence groups come from the supplied
`BiologicalUnitAssignmentArtifact`; H5AD sample columns cannot silently redefine
them. Reference matrices, metadata and marker-program files are resolved through
the supplied `ReferenceManifest` and verified by checksum before use.

CellTypist, scANVI, SingleR, scmap, Symphony and scConform remain P0-02 benchmark
adapters whose evidence can enter through the P0-02 profile. Spatial methods in
the catalog remain conditional and are not invoked by this package version.

For every requested channel the executor emits only these ratio types:

1. `target_identity_fraction`: configured product-role count / selected DataView;
2. `regional_fidelity_fraction`: configured regional numerator-state count /
   configured regional denominator-state count;
3. `whole_product_target_region_fraction`: configured regional state count /
   selected DataView.

An `unknown` or `ood` reconciliation record makes the channel `not_assessed` and
all three values null. Missing or unresolved mappings are also not converted to
numbers. A zero target-related denominator leaves only
`regional_fidelity_fraction` `unavailable` with null value, numerator and
denominator; it is never reported as zero. Typed reason codes preserve each
refusal or degraded-state cause.

## Outputs

One atomic run directory contains:

- one checksummed `TargetRegionalEvidenceResult` JSON;
- one independent checksummed `MeasurementResultV2` JSON for each normalized
  metric and requested channel;
- in expression mode, one checksummed `TargetRegionalMethodBundle` containing
  method-level evidence, software versions, biological units and provenance;
- one typed visualization-data JSON and one visualization-artifact-set JSON;
- exact TSV fallbacks for product-role composition and reference-state support;
- SVG, PNG and PDF renders of product-role/regional-state composition and
  source-separated reference support.

The figures preserve unresolved, unknown, OOD and unavailable observations.

The result binds the eleven core inputs and, when present, the expression asset
and method spec. ToolRun exposes the ratio projections and published artifact
checksums. Repeating the same inputs reuses identical bytes; changed inputs or
conflicting files under the same deterministic run ID fail closed.

`complete` means every requested ratio channel is complete. Expression-mode
execution is `partial` when a selected method returns partial or
`not_assessed` evidence, including the expected one-independent-unit bootstrap
case. Numeric candidate outputs remain `shadow`; otherwise score state is
`unavailable`. `domain_score` is always `null`. Spatial projection remains
`not_assessed`; the reference-support figure does not place product cells at
measured fetal coordinates.

## Interpretation boundary

The package proves deterministic contract binding and execution of the listed methods.
`candidate`, `complete` and `shadow` do not establish biological truth,
reference suitability, target identity, regional fidelity, potency, efficacy,
safety, clinical benefit, GMP release or product ranking. Scientific use still
requires reviewed external objects and independent validation.

`docs/bridge_spec_v0.1/target_regional_identity_task_card.md`.
