# P0-02 Cell-State Evidence

## Biological purpose

Test whether a pre-transplant product supports reviewed fetal ventral-midbrain cell
states while leaving unrelated neural and non-neural cells unresolved.

## Current biological status

- Broad fetal VM states can be explored in donor-held-out internal scRNA-seq data.
- Fine RG/Nb-derived states remain provisional because marker and external-source
  support are incomplete.
- Current inductive methods force cortical, motor-neuron, neural-crest and
  mesenchymal out-of-reference / out-of-distribution (OOD) controls into known
  fetal VM labels.
- Formal target, regional-fidelity and off-target composition conclusions are
  therefore unavailable.

Pseudobulk reference correlation is a reference-similarity summary, not
replicate-aware differential-expression inference. Marker/program evidence is a
complementary channel rather than an independent source because its curation
lineage overlaps the internal annotation.

No state or method is frozen. The next scientific step is review of the 25 state
definitions and marker cards, followed by locked external-source and OOD testing.

## Tool purpose

Explore expression neighborhoods, markers and within-population sample contrasts, or measure reference-backed candidate cell states without conferring scientific qualification.

**Input:** ATLAS-ingest-quick-v0.1 consumes declared raw counts and a typed P0-01 view, explicit pre/post-graft context, and a checksummed private sc/sn reference manifest. It intersects measured genes and fits reference-only centered PCA; no missing-gene zero imputation is allowed. EXPRESSION-exploration-v0.1 accepts the same typed QC view without a reference and exposes exploration/contrast parameters. Other modes require QC-qualified expression views with required `source_family_id` and `qc_profile_ref` asset metadata, a MeasurementSpec reference, declared scRNA/snRNA modality, annotation vocabulary, reference candidates and provenance. The exact QC-selected artifact is accepted with its parent binding and ordered observation checksum; the unfiltered parent cannot substitute for a selected view. The optional V3 handoff resolves the deployment-catalogued P0-01 structured-output index named by `qc_profile_ref`, including checksummed QC V2, biological-unit assignment and manifest artifacts. For raw-count inputs, feature columns resolving to the same non-missing normalized gene symbol are summed before normalization and recorded as a warning. Normalized-expression inputs must already have unique gene symbols.

**Output:** Quick atlas mapping produces a candidate label table, uncalibrated reference-neighbor gestation distribution and at most 600 positions copied from existing same-label, same-modality display-reference neighbors. Its chain and domain scores remain null. Expression exploration produces bound UMAP, marker and optional sample-contrast figures/tables; automatically computed Leiden groups additionally emit a full-observation Parquet with observation_id, umap_1, umap_2 and leiden, a ranked marker Parquet, and a private gene-major expression store with full feature/observation axes and zero-inclusive cluster means and detection fractions. Missing genes remain distinct from measured zeros; cell-level marker tests are exploratory, not independent biological replication. Raw pseudobulk counts and all analysis parameters are retained. Other modes produce backward-compatible Cell-State evidence plus an optional candidate-only V3 profile or separately bound CellTypist candidate profile with a development receipt, native measurements and unchanged auxiliary method artifacts, a typed whole-product reference-correspondence figure, and a static state-definition evidence registry. Every typed figure binds its complete table, static renders, exact data hash and evidence references; no output assigns a domain score. Exploratory grouping scientific artifacts retain stable method configuration and thread count, excluding volatile wall-clock and peak-memory telemetry.

**Runtime behavior:** Executable candidate; it emits raw measurements and never emits a domain score.

## Refusal Conditions

Quick mapping rejects undeclared counts, insufficient shared genes, invalid counts, mismatched modality, tree/resource hashes or typed QC binding; it does not supply calibrated OOD rejection. Expression mode rejects ambiguous sample metadata, non-integer declared raw counts and undeclared normalization. Inadequate independent samples or confounded design retain descriptive-only contrasts with null p-values. For reference modes, reference, vocabulary, MeasurementSpec, assay, data-view or checksum mismatch fails closed. Missing structured-index or typed-lineage inputs leave the legacy run successful but V3 unavailable; no lineage or positive composition is inferred.

Missing, unknown, unavailable, negative, and alert states remain distinct. No package may infer a clinical, safety, potency, GMP-release, or absolute product-ranking claim.

## Visualization Contract

Quick mapping positions bind the exact existing tree version; non-tree labels retain unavailable positions rather than being forced onto a neural node. Gestation values are reference-neighbor frequencies, not confidence intervals or validated sample age. Expression mode reuses the typed figure registry, source/table bindings and SVG/PNG/PDF exporter; UMAP adds metadata/gene/QC coloring and group filtering with unchanged full-view denominators. Marker plots show up to 40 top-ranked markers; full tables retain every requested rank. Whole-product and submitted-group reference correspondence is shown with explicit denominators. A separate static registry distinguishes current label occurrence, dependent context, unrecorded source mappings and unrun external assessment; it does not represent query-specific product support.

Every formal chart must retain its data version, denominator, units, evidence references, and missing-state semantics.
