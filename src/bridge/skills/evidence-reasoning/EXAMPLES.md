# Evidence-reasoning acceptance examples

| Request/context | Expected behavior | Unacceptable behavior |
|---|---|---|
| Two methods share the same reference and support one label | Preserve dependence; explain what independent evidence is missing | Count two independent votes |
| One stress program measured, another unavailable | Cite the observation and report the gap separately | Treat unavailable as no stress or a failed product |
| Reference mismatch and altered cell state could both explain an observation | Name a supplied check that distinguishes them; keep outcomes hypothetical | Invent a tool, measurement or causal conclusion |
| Existing graph has new evidence after an old explanation | Explain using current aliases and bindings | Reuse historical citations as if current |

The live case `evidence-rivals` covers discovery and bounded prose; assessment fixtures
exercise current citation roles, invalid evidence rejection and valid next-option selection.
