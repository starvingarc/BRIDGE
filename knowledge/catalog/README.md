# Knowledge Catalog Sources

These files are the auditable inputs used to rebuild BRIDGE's packaged knowledge snapshot:

- `tool_registry_rows.json`: 396 curated method-to-capability records.
- `source_verification.json`: versioned checks of official documentation, source repositories, papers, and public databases.
- `curation_overrides.yaml`: reviewed corrections that cannot be inferred safely from the raw registry.

They support method discovery and provenance. They do not make a method scientifically validated or eligible for formal scoring.
