## Implemented scope

- Versioned 25-state development decisions and the CellTypist / energy candidate
  runtime are integrated. Development failed its entry criteria; locked testing
  was not run. This is an explicit scientific result, not a qualified release.
- Native cell-state and exploratory process observations feed the existing
  sufficiency/compiler/query chain with exact DataViews, measurement definitions,
  denominators and shared-data dependencies.
- Competing explanations retain support, opposition, missing evidence,
  discriminating checks, expected observations and immutable version history.
- A shared analysis snapshot binds private Chinese HTML and JSON/CSV/SVG
  attachments to verified statements, product facts and source measurements.
- Confirmed fact or selected-object changes expose affected/reusable receipts;
  original inputs, runs and reports remain unchanged. No correction executes
  a new analysis automatically.
- Registered comparison and genuine linked graft inputs have separate conditional
  entry and confirmation; missing graft data cannot become a graft assessment.
- User documentation and frontend directory naming are simplified. Agent
  collaboration requirements have one maintained source in [AGENTS](../AGENTS.md).

[Cell-State Scientific Qualification](p0-02-cell-state-scientific-freeze.md) and

do not establish product-role accuracy, stage compatibility, independent
replication, a ScoreContract, clinical efficacy/safety or release qualification.

an independent vote. Scope approval grants only bounded execution, not scientific
approval, publication, merge or deployment.
