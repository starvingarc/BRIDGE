# 用户旅程与功能路线

本文按湿实验用户实际使用 BRIDGE 的顺序，列出工作台每一步的功能、当前状态、对应 issue 与实施顺序，
是工作台功能进度的**唯一维护源**。项目总体阶段（私有协作、发行、公网、公开发行）见 [总体路线图](../docs/ROADMAP.md)，
界面细节见 [BRIDGE 产品设计](bridge-product-design.md)，对象与接口见 [研究内对象](research-objects.md)，
流程决定见 [工作台流程](workbench-flow.md)。2026-10-13 建立，2026-10-14 按产品负责人的决定重排为 A–G 与 X 段。

GitHub 上的对应关系：每段一个 milestone（A 准备方案 … G 移植后，X 平台与验收），每项功能一个带 `roadmap` 标签的 issue，
置顶的“路线图总览” issue 汇总各段任务清单。

## 1. 原则

- **按用户使用的顺序做，逐个功能做完。** 前一步的结果是后一步的输入；一个功能做完再开始下一个。
- **完成的标准是真实数据跑通。** 每个功能必须在三套预设方案（第 2 节）上用真实数据走通、在浏览器里核对过，才算完成；
  合成数据只用于边界情况的测试。组件测试通过、接口存在、分支合并都不等于完成。
- **先做 PC 网页端。** 手机端暂缓，不作为验收或合并要求，只保证不出现无法操作的严重问题。
- **工作台是唯一主线。** 旧的会话式研究空间里已有的 QC、证据图和报告逐步收进工作台：QC 与分析结果挂在样本下，
  证据图与报告挂在实验与研究下、在产生它们的地方查看，尽量复用已有组件；旧界面保留为"历史会话"。
- **标准分析自动运行，其余经提议后确认。** 关联数据后自动运行 QC、双细胞与细胞周期、标准映射与分化链、常规单细胞分析、
  状态质量与安全门控；差异表达、通路富集、轨迹、批次整合、跨实验比较等由 Agent 或用户提出，确认后执行。
- **不设总分。** 定量评估就是五级分化链（映射栏中的漏斗、雷达图与按阶段切换的主要数字），它是分层映射结果按关卡的汇总，
  不是另一套判定；旧的五域评分不再展示，不做加权总分或排名。细胞状态质量、安全门控与发育各自成面板，不折算成分数。
- **演示视频最后制作**，在核心功能全部完成之后。

## 3. 维护规则

- **新增功能**：先在第 4 节对应段落加一行（写清用户看到什么），再建 issue（标签 `roadmap`，挂对应 milestone），把编号填回本表。
  较大的功能在第 6 节补一段做法与验收。
- **状态变化**：PR 合并或部署时，在同一 PR 中更新本表状态；issue 关闭后总览 issue 的任务清单自动更新，不另手改。
- **决定变化**：产品负责人改变做法时，在对应段落写明日期与新做法，旧做法不保留为待办；必要时在 [决策记录](../docs/decision-log.md) 记一条。
- **状态用语**：**已上线** = 已合并并部署到内网服务；**已合并** = 在 main 上、尚未部署或尚未用真实数据验收；
  **进行中** = 有人在做（分支或 PR 未合并）；**计划** = 已有 issue、未开工；**暂缓** = 明确推迟。
  “已上线”不等于三套预设数据验收通过或科学资格成立，验收单独记录。

## 6. 各项做法与验收

以下为已确定的做法；编号沿用此前的 ①–⑨，括号内为现在所属的段与 issue。

### ① 发育树上的流带（C，已上线）

问题：原来每次实验画成一条穿过树的路径，取样点放在各枝占比的加权中心。真实样本常分布在相距很远的几根枝上
（例如 61% 多巴胺能、31% 谷氨酸能），加权中心落在没有细胞的空白处，这条线没有含义。

做法（产品负责人选定）：
- 从 hPSC 起，沿发育树自身的枝干分叉流出；每段枝的粗细等于流经它的细胞占全部细胞的比例
  （该枝及其下游各标签的 `tree_position` 之和），细胞落在枝末。小于 1% 的分支不画。
  "未落在树上"不进入流带，在透镜中列出。
- 打开一次实验时显示所选取样天的流带，切换取样天时粗细平滑过渡；全树视图中各次实验显示最近一次取样的流带，
  未聚焦的淡出，聚焦一次实验时其余隐藏。
- 点击流带选中该实验；取样天在透镜中切换。示例方案用同一画法。
- 结果与当前树版本不一致时不画流带，与细胞落点的规则相同。

前端：画法、交互与示例；后端无改动。
现状：已实现（流带画在参考细胞之上、样本细胞之下，聚焦时参考细胞调淡；全树视图悬停显示实验与取样天）；已完成限定范围的受控数据界面核对；预设时间序列验收仍待完成。
验收：GSE204796 的 D8 → D35 能看出细胞从祖细胞枝流向神经元枝；Boost 与 Boost+ 同一天的流带可对照。

### ② QC 收进样本详情（C，已上线，#178）

结构（2026-10-14 产品负责人选定，取代先前"实验页面分方案｜结果两栏、树在结果栏"的设想）：

- 左栏只有 培养箱 · 比较 · 报告（左栏随后重整，见 #191；报告移到产生处，见 #189）。在培养箱点开一张卡片，直接是这次分化的方案图；全研究叠加的发育树暂放在"比较"下，功能 ⑥ 再扩充。
- 取样点画在方案图的天数轴下方，按状态区分（虚线待测序、半实心映射中、实心已完成、橙色未完成），悬停显示细胞数与主要落点；
  同一天的多个样本是这一天的多个批次，共用一个点（标 ×N）。点开先看「全部批次」：各批次 QC 数字一表、计数/基因/线粒体分布按批次叠画
  （各按本批次比例）、细胞周期与映射逐批并列；顶部切换到单个批次即原来的样本面板。各批次分别分析，并排对比、不合并数据；
  合并的 UMAP 需批次整合，归多时间点整合（#186）。一个文件内含多个捕获批次的逐批 QC 需后端在逐细胞表带批次列，另提。
  在轴上点某一天即在那天登记取样。
- 点取样点，从右侧滑出这个样本的面板，方案图收窄留在左边；面板分 映射 · QC · 记录（2026-10-15 起双细胞与细胞周期都在 QC 栏），关联数据、补充说明、重试映射也在面板里。
  映射栏有一张只画这一天细胞的小发育树，可展开为原来的完整三维树（取样天切换、基因着色照旧）；发育树只作为映射结果的可视化。
  以后的分化链、状态质量与发育面板加在这一行栏目里。
- QC 栏：可用性（原因放在悬停提示里）、细胞数、基因数与五项中位数；三张分布图与线粒体占比 × 总计数密度图由前端按逐细胞
  Parquet 重画（可悬停读数、随深色模式）。界面少放说明文字：不列未评估项、不放表格预览，"下载数据"与"原图"在栏底一行。
  2026-10-15 产品负责人要求去掉文库复杂度散点（看不懂用途）与多余说明。
  映射进行中 QC 先出现（预览实例上 QC 约 10 秒登记、映射约 110 秒完成），面板每 4 秒刷新。
- 记录栏：该样本登记的全部分析，编号是登记先后，不代表采用哪一次；可打开较早的 QC。
- 后端：自动运行的 QC 与映射登记为该样本的分析，前端按样本读取分析与结果文件（基于样本分析接口，#169）。
- 现状：已上线（#169、#178 合并，2026-10-14 部署）；三套预设数据逐单元验收见 #137。
- 验收：三套方案的每个取样单元都能从工作台打开 QC 结果，无需进入旧界面。

### ②a 方案确认即记录实验（A，已上线，#179）

2026-10-14 与产品负责人对齐的湿实验模型：

- 一个研究下有多个方案；方案录入（上传文档或手动）后由用户核对确认，确认即记下这次实验，同时填细胞系与开始日期
  （可留空，例如公开数据）。不再有单独的“开始”步骤，界面不再按“轮”称呼实验。
- 卡片与页面标题用方案名；改了方案是新版本（标题加 v2），确认后是培养箱里的一张新卡；同一方案再做一批（如换 H1）
  从方案页"再做一批"进入，标题后加细胞系与开始日期区分（② 中已先按此规则命名）。
- 同一张卡下 D8、D14 … 的取样是它的时间序列。
- 后端不改：确认时前端依次确认方案版本并开始执行（Run）；执行的内部名称由细胞系与日期生成，界面不显示。
- 现状：已上线。后端已有的回顾性实验记录（导入的公开数据）按普通卡片显示，不另设入口。

### ②b 拖拽编辑方案图（A，已上线，#179）

- 拖试剂条两端改起止天、拖整条平移，按天对齐；点试剂条就地改浓度，旁边提示文献报告的浓度。

### ③a 样本面板中的常规单细胞分析（C，#184）

2026-10-14 产品负责人选定，参照常规单细胞分析流程（QC → 降维与聚类 → 标志基因 → 注释 → 轨迹与差异）：

- 自动运行（标准套）并在样本面板各占一栏：细胞图谱（样本自身 UMAP 与 Leiden 聚类，可按聚类、基因、QC 指标、
  映射类型着色，悬停读数）、Marker 基因（聚类标志基因点图、任意基因分布）、细胞周期（各阶段占比，与异常增殖门控相关）。
- 差异表达、通路富集、样本内伪时间、RNA velocity、细胞通讯：Agent 或用户提出，确认后运行，结果标为探索性。
- 后端：标准"基础单细胞分析"工具在 QC 之后自动运行并登记为样本分析，产物为逐细胞表与聚类标志基因表，参数与随机种子固定在登记里；
  前端负责交互图。栏目增多时样本面板可拉宽成整页。
- 双细胞在 QC 栏：有结果时显示候选数与占比（小于 0.1% 写作"<0.1%"，不写 0）、Scrublet 分数分布（候选细胞单独着色）；
  未检测时写明原因，缺捕获批次的样本可在此补充（一次捕获填批次名，或填所在列），提交后重新跑该样本的基础分析，旧结果留在记录。
  阈值属于单个捕获批次：全样本只有一个批次时画阈值线，并以虚线叠画 Scrublet 模拟双细胞的分数分布供判断阈值是否可信；
  多个批次时改列表，逐批给出细胞数、候选数与各自阈值，不画统一阈值。只做标记，不删除细胞。
- 细胞周期是 QC 栏的一节（2026-10-15 产品负责人决定并入 QC，不再单独成栏）：S 或 G2/M 期细胞比例、G1/S/G2/M 占比条与计数（点选阶段可在下面两张图中单独突出）；样本自身 UMAP，
  可按阶段、S 评分或 G2/M 评分着色，悬停显示阶段、簇与两项评分（UMAP 来自细胞图谱分析，按 observation_id 与周期表关联，
  细胞图谱登记后才出现）；S × G2/M 评分散点，坐标取中间 99% 的细胞，超出的画在边上为空心点。不放读法说明与逐细胞表。
  没有算出评分时只写原因，不画空图。
- 登记或关联数据时，数据说明多一个选填问题"捕获批次"：整个文件来自一次捕获（填批次名）、文件里有几次捕获（填所在列）或不清楚；
  不清楚则不检测双细胞，其他分析照常。批次名和列名由用户填写，不从文件名或列名推测。
