# BRIDGE 产品设计

**状态：** `approved_direction; not_implemented`。本文记录 2026-10-12 产品负责人逐项确认的方向，
不是已交付能力。被推翻或扩展的现有合同在实施对应改动时同步修改，见[待修改合同](#待修改合同)。

## 1. 定位

- BRIDGE 是腹侧中脑发育图谱论文的最后一部分：团队自测的人胚腹侧中脑 scRNA/snRNA/空间数据、
  发育分析与湿实验验证在前，Agent 用该图谱与已发表数据帮助湿实验研究者评估分化产品并迭代实验。
- 目标是随论文发表并提供可实际运行的服务；当前先作为实验室内网工具。
- 不设截止时间，以质量为准；每一轮可用版本须交给实验室研究者实际使用一次，再决定下一轮打磨。
- 细胞亚群命名由图谱分析持续更新，不在本计划范围内。本计划内所有功能必须在命名换版后
  通过重算刷新，不得硬编码具体亚群名。

## 2. 演示场景与完成标准

上传实验室任一主要分化方案的数据 → Agent 展示全部能力 → 与全部已登记方案一起对比 →
证据图谱指出差异来源 → 给出下一步分析或实验方向 → 用户确认后继续分析。

## 3. 界面与交互

### 3.1 原则

- 从湿实验研究者的视角出发：先回答"我的细胞现在怎样、今天要做什么、下一轮改什么"。
- 体外 ⇄ 体内是核心隐喻：每一轮分化都是一条穿过胚胎发育图谱的路径。
- 一次只看一样东西，文字少；结论一句话，细节点开再看。
- 美观与易用同等重要：柔和明亮的实验台风格（Soft Lab Console），玻璃质感面板，支持深色模式。
- 研究者自建方案与文献方案外观一致，不区分"实验室"与"公开"。
- 原型：私有 artifact `BRIDGE 工作台原型`（示例数据）；实现以本文为准。

### 3.2 结构

- **左侧栏**（2026-10-14 产品负责人选定，见[路线](user-journey.md) #191）：顶部研究名为切换菜单（切换研究、所有研究、历史会话）；
  新建分化；导航为培养箱、比较、资料（上传的文件与生成的报告）；下方为实验列表，按进行中、已完成、草稿分组，点击直接打开方案图；底部账号与设置。
- **实验页**即方案图：天数轴下是取样点，点开右侧滑出样本面板（映射、QC、记录等栏目）；发育树是映射结果的可视化。
- **报告**在产生它的地方生成与查看：实验页右上角、比较页；所有报告文件同时列在“资料”中，左栏不放报告（#189）。
- **研究内对象有类型**：分化方案（带版本）、样本与批次、数据集、评估结果、比较、下一步计划。
  这些对象由 Agent 在对话中提出、用户确认后落地；各视图只渲染这些对象。
- 权限：内网版仅供实验室内部使用；研究共享给同一服务上的同事列入路线（#194），后续按"实验室为一等对象、项目默认私有
  可分享、方案库在实验室层"演进。

### 3.3 培养箱（研究首页）

- 顶部一句问候与"今天有 N 件事"：由各方案结构化步骤得出当日操作（如"D9 · II · 加 SHH 与 PM"）
  及新线索。
- 每个方案一张卡片，中心是圆形培养皿插画，按当前阶段显示不同的动态示意。
- 阶段收拢为：扩增期；Stage I 神经诱导；Stage II 底板诱导；Stage III 底板祖细胞；
  Stage IV 神经元成熟；以及冻存（待移植）、移植后、未开始三种状态。卡片标注如 `D16 · Stage III`，
  下方写阶段名，进度条四段对应 Stage I–IV。阶段边界由方案步骤决定，表中天数只是默认值。
- 插画采用柔光玻璃培养皿的形象化风格（不追求显微写实），八种状态各一张原创底图
  （[来源与用途](../docs/assets/culture-dish-artwork.md)）。前端叠加轻量动态（呼吸、摆动、漂移、明暗、
  移植光晕，以及正在培养时的玻璃光泽），各卡错开节奏，系统设置减少动态时停止。
  插画不随测量数据变化，比例只在分化链视图中表达，避免把示意颜色读成测量值。
  研究者上传的显微照片后续可作为卡片封面。
- 筛选：全部 / 分化中 / 已完成 / 已移植。
- "等你确认"队列：Agent 建议的下一步分析，标明探索性或正式工具与预计耗时，确认后执行。

### 3.4 发育树

- 图谱渲染为可拖动旋转的三维发育树；默认缓慢自转。
- 树形由数据决定、层级受约束：祖细胞 → 各区域 RG → 同区域 Nb → 神经元大类 → 亚型；
  神经元大类连到哪个 Nb 由 scVI 潜空间上的 PAGA 连通度决定；横轴为 Palantir 伪时间。
  当前原型实测：DA ← 底板 Nb（0.92），Glut、GABA ← mBIP Nb；mBMP Nb 无明确神经元后继。
  直接三维 UMAP 与无约束 PAGA 最大生成树均不成可读树形，不采用。
- 动态：打开时按伪时间从根部长出；一道伪时间光波沿树流动；孕周回放（GW7–25）与
  谱系/孕周着色切换。
- 每轮显示为从 hPSC 沿树自身枝干分叉的流带，枝的粗细等于流经它的细胞比例，细胞落在枝末（2026-10-13 起取代"一条穿过树的路径"：真实样本常分布在相距很远的几根枝上，加权中心落在空白处）。细节与实施顺序见[用户旅程与功能路线](user-journey.md)。
- 基因着色：可把树上的样本细胞与参考细胞按某个 marker 的表达着色（同 UMAP 上的基因表达图），
  用来直接查看候选底板等标签背后的表达证据。默认面板 FOXA2、LMX1A、OTX2、EN1、CORIN、SHH、
  NR4A2、TH、DDC、PITX3，可调整；其中 EN1 与 CORIN 用于区分尾侧与头侧腹侧中脑祖细胞。
  着色只展示表达，不改变任何指标。

### 3.5 取样点视图

- 2026-10-14 起取样点画在方案图的天数轴上，点开从右侧滑出样本面板（映射 · QC · 记录；双细胞与细胞周期在 QC 中），见[用户旅程](user-journey.md) ②；
  映射栏的小发育树可展开为完整发育树，下面各条描述完整发育树里的透镜与交互。
- 点击取样点，镜头推近，该样本细胞从取样点飞落到发育树上对应的亚群位置。
- 右侧透镜：主要数字（按阶段切换，见 6.1）、五级分化链圆环、对应体内孕周、取样天数切换。
- 快速映射 v0 没有分化链数值与目标比例时，透镜不放大数字（2026-10-13 产品负责人选定）：列出细胞落在哪几根枝及占比
  （前三枝、其余合并、"未落在树上"），分母都是全部细胞；写明"快速映射 v0 · 候选结果"、"分化链指标：尚未计算"，
  孕周写作"近邻参考 ≈ GWa–b"，参考、细胞数、树版本与方法局限放在"方法与版本"里。链指标算出后，主要数字回到原位。
- 只有结果的树版本与当前发育树一致时才画细胞，否则说明版本不同、不画；合成示意树上不画真实结果。
  样本细胞按图例 A 画得更大并带外轮廓；落在同一参考位置的细胞合成一个点、按个数放大。镜头按细胞分布取景。
- Agent 在图上落气泡说一句结论（如"一半长到了 mBIP 那根枝上"），附"为什么 / 下一轮"。
  没有链指标时气泡只陈述落点（如"落在多巴胺能神经元最多（61%）"），不写"各级未见偏低"。窄屏时气泡并入透镜。
- 着色可切到"基因"（结果保存了 marker 表达时才出现）：透镜里选默认十个基因之一，参考细胞与样本细胞用同一色阶
  （浅 → 青 → 深，99 分位封顶），同一位置的多个样本细胞取平均，不在映射参考里的细胞显示为浅灰缺失而不是 0。
  只展示表达，不判定阳性，不改标签、链或评分；表达数据的树版本、基因集合或归一化与结果不一致时不着色并说明。
  表达矩阵只在打开基因着色时读取。
- 底部常驻"问 BRIDGE"对话条，完整对话从右侧滑出。探索性结果在对话中带明确标记。

### 3.6 方案图

分化方案的可视化与交互，回答"我做了什么、今天做什么、和别人差在哪、下一轮怎么改"。

- **形式**：横轴为天数，上方四条阶段色带（Stage I–IV）及对应阶段培养皿缩略图；
  下方按信号通路分泳道：SMAD 抑制、WNT、SHH、FGF、Notch、成熟与存活、其他补充。
  每个试剂是其添加窗口上的一段条，粗细或深浅表示浓度，图标区分小分子/蛋白/复合补充剂。
  "今天"竖线、取样点标记（与发育树节点联动）。无可靠日期时用顺序图，不伪造比例时间轴。
- **试剂卡**：点击试剂显示结构图、作用机制、本方案剂量与窗口，以及小分子库中各文献报告的
  浓度与窗口分布（来自 `examples/protocol-visualization` 小分子库，32 个条目、带来源定位）。
  原文出处可回溯到上传版本。
- **与评估联动**：泳道与分化链对应——WNT/FGF ↔ 中脑定位，SHH ↔ 底板化，成熟与存活 ↔ DA 命运。
  某一级偏低时对应泳道高亮，Agent 的线索指向具体试剂与窗口。
- **对比**：叠加另一方案（如 Boost+）为虚线轮廓，按天对齐，差异处标注（剂量、窗口、有无）。
- **下一轮草案**：Agent 的方向建议以虚线形式画在谱上（如延长 SHH 窗口）；用户确认后
  生成新版本方案，出现在培养箱上为"未开始"。剂量与时序由研究者决定，Agent 只给方向。
- **录入**：上传方案文档后沿用现有 protocol 形式化流程（BPL 草稿、编译、来源与覆盖检查、
  人工核对），不确定的值在谱上标为待确认。导入时在对话框内等待并显示已用时间，完成后直接打开草稿
  （后端为同步请求，后台导入需先改为后台任务）。
- **原文核对**（2026-10-13 确认；2026-10-15 改为按需打开）：点开方案只显示方案图；在试剂详情点「在原文中查看」，
  或在待核对清单点「打开原文」，原文才在方案图左侧打开并定位到该试剂，可随时收起。原文中被采用的值高亮，
  点试剂高亮其出处、点出处打开对应试剂；原文没写清的地方列在原文上方。窄屏为"原文 / 方案图"切换。
  高亮只证明字面出现，不证明对应正确。
- **未知时间**：只知一端的试剂从已知端画起、向未知端渐隐并标"?"；两端都未知的放在泳道下方的
  "时间待定"托盘；绝不画成 D0。时间未补全、剂量未填或仍有待核对项时不能确认。
- **整份方案核对**：导入版本的整份方案待核对项（原文、总天数、阶段、操作）逐项确认，
  "原文"一项须在原文显示后才能勾选；只清试剂标记不能代替。

### 3.6a 登录页与标志

- 整页是俯视的一只培养皿：四角露出皿沿，细胞在培养液里带惯性地游动，靠近的细胞之间有淡细丝相连；
  把一个细胞拖到另一个上会留下一条稳定连接。登录卡片居中，像浮在培养液上的玻璃片；细胞碰到卡片或标志会
  轻微压扁后弹开，碰撞点泛起淡涟漪。纯装饰，不表达任何数据；系统要求减少动态效果时静止。
- 标志是一枚玻璃单细胞，细胞核微微朝向指针。登录页上它是菜单按钮：展开时细胞一分为二、由一根丝相连
  （即"桥"），菜单含关于 BRIDGE、使用须知、深色 / 浅色。其他页面的侧栏使用同一标志（不带菜单）。
- 深浅色可手动切换并记住；未选择时跟随系统。注册时的使用须知仍在卡片内供确认。
- 登录外观提供清透、晨光、珠光三个候选，共用表单和细胞交互。默认清透；`?login-review=1` 显示候选切换，
  `login-look=quiet|morning|opal` 可直接打开对应外观，不改变账号或研究设置。
- 拖动可向附近两个细胞建立弹性连接；窗口缩放保留已有连接。取消指针或窗口失焦释放拖拽；
  细胞不进入表单。减少动态效果时停止自动绘制，仍可直接移动细胞；后台页面暂停动画。
- 窄屏及低高度页面使用自然滚动，注册须知与确认按钮均可到达。Logo 菜单支持方向键、Escape 和 Tab 离开。
- 登录默认只显示品牌、用户名、密码、登录与注册入口，不展示重复标题、口号或装饰操作说明；注册保留必要使用须知。

## 4. Agent 架构

### 4.1 正式证据层与探索层

| | 正式证据层 | 探索层 |
|---|---|---|
| 工具 | 已注册、已审阅的 Tool Package | Agent 经用户同意后在隔离沙箱中下载、编写并运行 |
| 结果去向 | 评估轴、正式证据图节点、报告结论 | 标为探索性分析，在证据图中单独显示，可作为下一步建议依据，不进入正式评估结论 |
| 演进 | 开发者根据使用情况补充默认工具层 | 反复使用且有价值的探索性分析由开发者升级为注册工具 |

两层都不得修改 reference、阈值或测量定义。执行环境为每用户隔离沙箱。

### 4.2 下一步建议

- 由工具分析、证据图、文献检索和历史记录共同支持，给出方向级建议，不给未经验证的小分子剂量与时序。
- 建议以可执行的下一步分析或方案图上的草案呈现，用户确认后执行。
- 目标是让 Agent 像细胞分化研究人员一样思考：经验来自与研究者的讨论，并随使用积累。

### 4.3 记忆

- 范围：项目内、多人、实验室三级。
- 个人与项目记忆自动积累；进入共享范围的记忆须由用户确认，并保留来源与提出者。
- 记忆不得改变 reference、阈值或测量定义。

### 4.4 模型

默认使用当前已部署的 DeepSeek 模型服务；模型配置继续按账号独立管理。

## 5. 对比

- 默认对比对象为全部已登记方案；Agent 与用户讨论并确认对比集合。
- **Boost/Boost+（E-MTAB-14729）与 RC17（GSE200610）解封为比较对象**，只用于比较，
  不用于训练、校准、阈值或参考构建。
- **方案库**：先做一轮文献调研补全清单。每个方案包含结构化方案（阶段、天数、小分子与浓度，
  以方案图展示）、按同一流程统一处理并缓存的数据（以命名版本与参考版本为缓存键，可一键全量重算）、
  可比性元数据。方案结构化由 Agent 辅助抽取、人工确认。
- 发育树上所有方案路径同时可见，聚焦一个时其余淡出；同阶段对比由 Agent 推荐可比较、
  仅作背景、排除（附原因）三类对象，用户确认后逐项对比。
- 视图设计参考 BrainSTEM 与 Studer 组近期预印本，并以可交互拆解为重点。

## 6. 定量评估

### 6.1 原则

- 分化链指标是带分子分母的原始条件比例，不是 `domain_score`；`domain_score` 的现行规则不变。
- 定量指标由本项目自行定义并版本化冻结；先冻结、后运行对比，修改即升版本，旧结果保留。
  评分版本同时绑定命名版本与参考版本。
- 指标锚定体内图谱，不锚定对比集合；加入或移除对比对象不改变任何产品的数值。
- 每个数值由公开公式从原始测量直接得到，可下钻到分子、分母与证据链。
- 缺失显示为"未测量"，不画成 0。门控警报不折算进任何指标。
- 不设加权总分。卡片与对比只显示一个主要数字，按样本所处阶段切换，数字旁始终写明它是哪一个：
  Stage I–III 及冻存的祖细胞产品显示**候选底板谱系比例**（到第 3 级的乘积，n(C3)/N）；
  Stage IV 及移植后显示**DA 比例**（五级乘积，n(C4)/N）。祖细胞阶段尚未表达 DA 程序，
  若始终用五级乘积，会把正常的早期产品误读为方案差。
- 自洽性检验：图谱留出的体内样本为阳性对照；OOD 面板为阴性对照；时间序列为方向检验。

### 6.2 分化链：圆环、雷达图与漏斗图

五级条件比例，每级只在通过上一级的细胞中计算；保留的细胞集合逐级嵌套，每一级流失的细胞互不重合。
未能判定的细胞留在该级分母中、不算通过；任一级不可测时，跨过该级的乘积显示为"未测量"。

| 级 | 维度 | 分母 | 对应方案泳道 |
|---|---|---|---|
| 0 | 脱离多能 | 全部细胞（未能判定计入） | 分化启动 |
| 1 | 神经谱系 | 已脱离多能的细胞 | SMAD 抑制 |
| 2 | 中脑定位 | 神经细胞 | WNT、FGF |
| 3 | 底板化 | 中脑细胞 | SHH |
| 4 | DA 命运 | 底板细胞 | 成熟与存活、Notch；同时给出 Palantir 命运概率与早期 DA 标记两种估计 |
| 5 | DA 亚型（A9/A10） | DA 细胞 | 仅在提供移植后数据时显示，数据来自移植物 |

- 同一组数值以取样点透镜中的圆环、雷达图（多方案叠加、Boost+/RC17 参照轮廓）与漏斗图
  （逐级保留与流失去向）展示。
- 中脑定位需要全脑参考判断间脑与后脑成分，使用已有的全脑参考注释对象。

**演示版判定规则（chain-v1-demo，2026-10-13 产品负责人确认）**。以下均为操作性定义，结果标注版本与"候选"，
不等于经湿实验验证的身份；独立校准完成后升版本替换，旧结果保留。

- **第 0 级 脱离多能**：已登记的 PLURI 候选程序打分，阈值以多能细胞为阳性对照、胎儿细胞为阴性对照校准。
  自测图谱与 Braun、Zeng 胎儿数据不含多能细胞，只能作阴性对照；若其中没有可用的阳性细胞，
  加入一份公开 hESC 单细胞数据（下载前列出数据集供确认）。校准完成前显示"未测量"，乘积从第 1 级起算并注明。
- **第 1 级 神经谱系**：中枢神经系统谱系的细胞通过，包括神经祖细胞（含底板与放射状胶质）、神经母细胞、
  神经元及中枢胶质（星形胶质、少突胶质谱系）；神经嵴及其衍生细胞、血管软脑膜与血管周样细胞、间质、
  非神经上皮不通过；归类不清计为未能判定。胶质算通过：腹侧中脑产品与胎儿移植物中星形胶质都是常见组成，
  而血管周样细胞是体外来源特有的非神经成分（[Tiklová 2020](https://doi.org/10.1038/s41467-020-16225-5)），
  这样胶质的多少在后续各级体现，不被误判为"神经诱导失败"。底板来源的祖细胞通常不表达 PAX6，
  因此不以 PAX6 计这一级。界面名称用"神经谱系"而不是"神经诱导"，避免与 Stage I 阶段名及
  按 PAX6 计的"神经诱导效率"混淆。
- **第 3 级 底板化**：映射到 RG_mFP、Nb_mFP 及中脑 DA 后代标签的细胞作为"候选底板谱系"通过。
  这些标签的底板解剖身份尚未经湿实验确认（当前仅确认 RG/Nb 大类），界面标注"候选"，
  并配合发育树基因着色（3.4）直接展示 FOXA2、LMX1A 等表达供判断。基于底板程序与竞争程序、
  经对照校准的 marker 门控完成后升版本替换。
- **第 4 级 DA 命运**：演示版只给 DA 转录程序证据（TH、DDC、NR4A2、PITX3 协同及竞争程序）。
  现有 Palantir 结果的两个终末状态均为 GABA、没有 DA 终末，命运概率须先策展终末状态并重算，之后再并列显示。

### 6.3 不在分化链上的内容

- **细胞状态质量**：体内相似度、应激程序水平，单独面板。
- **安全门控**：残余多能性超阈值、异常增殖，以警报显示。
- **发育**（不打分）：按细胞类型给出对应体内孕周分布；伪时间位置（早期分辨力高于孕周）；
  命运走向。超出参考覆盖范围的部分报告边界，不压到边界孕周。

### 6.4 移植后衔接

移植前评估与同一制剂的移植后结局（含第 5 级 A9/A10 组成）通过制剂对象关联展示。
移植物数据仍是独立后验证据，不回填移植前数值；配对样本不足时，移植前指标与移植后结局的关系
只作探索性观察。成人黑质/腹侧被盖区数据可作为 A9/A10 判定参考。

### 6.5 空间与三维联动

- 点击发育树的枝或分化链某一级，在对应孕周的空间切片上高亮该亚群的体内位置，并在三维胚胎模型中
  标出对应区域。
- 发育面板中某细胞类型对应的孕周决定加载哪个时间点的三维模型与切片。
- 复用已实现的[产品 UMAP 与空间参考联动](product-spatial-link.md)和三维解剖视图；三维胚胎模型
  正依据空间切片单独修正，接入以其产出为准。
- 边界：联动展示的是参考中的亚群位置与类型对应，不是产品细胞的空间定位；切片配准、解剖方向与三维
  注册未经验证前，不作空间位置或三维定位声明。

## 7. 图谱与参考

- 以最新的 sc/sn scVI 整合图谱 v1 为准（148,922 profiles，12 个胚胎，GW7–25；scRNA GW7–20，
  snRNA GW14–25），其 L1/L2/L3 命名与 BRIDGE 当前词表一致。较早的 GW6–20 整合对象为历史版本。
- 发育轴向前延伸使用 Braun 2023 与 Zeng 2023 的腹侧中脑相关细胞；界面不必单独标注外部参考，
  但来源记录必须保留每个细胞的数据来源。
- 标准映射"先快后稳"（2026-10-13 确认）：快速版 v0 用 Scanpy ingest（参考 PCA 空间近邻）传递孕周、
  伪时间与亚群标签，发育树位置取近邻参考细胞在树上的位置，结果标注"快速映射 v0"及参考与方法版本；
  稳定版重训可投影（scArches）参考模型后替换，两版并存、不混用潜空间。现有发育树所用 Top1 scVI
  模型的训练产物目录已不存在，无法直接投影到该潜空间。
- 参考按样本类型选择：移植前样本只用 sc 参考（`REF-CHEN-VMB-SC-v1`）；移植后样本用 sn 参考
  （`REF-CHEN-VMB-SN-v1`）。
- 孕周估计需留一胚胎验证；以 scRNA 为发育轴主干以避免模态与孕周混杂；
  多数孕周仅一个胚胎，结论须注明。
- 图谱论文中的 Monocle/Palantir 轨迹用于讲述谱系；BRIDGE 使用可投影的估计器，两者分工，
  不在论文中出现两套互相矛盾的"发育时间"。
